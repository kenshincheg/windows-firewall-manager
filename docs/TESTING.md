## Обычный запуск тестов

В Developer PowerShell / x64 Native Tools Command Prompt:

```powershell
cargo test --locked
cargo clippy --all-targets --locked
```

Обычные тесты модели, UI и отсоединённых COM-объектов не добавляют и не удаляют рабочие правила.

## Реальные сценарии

В `src/ui/rules/live_tests.rs` находятся отдельные `#[ignore]`-сценарии. Их запуск требует администратора, явного режима `FWMGR_LIVE_DELETE` и существующей резервной копии `FWMGR_LIVE_BACKUP`.

- `live_rule_lifecycle_matrix`: создаёт, изменяет и удаляет собственные временные отключённые правила, сверяя исходную политику.
- `live_verify_duplicate_deletion`: проверяет удаление временных копий при разных и одинаковых именах.
- `live_remove_redundant_copies`: отдельный обслуживающий сценарий, который удаляет лишние реальные дубли. В обычные проверки и проверку выпуска он не входит.

Локальные `.wfw`, журналы и снимки рабочей конфигурации не публикуются. Не запускайте все игнорируемые сценарии как обычный тестовый набор: один из них предназначен для реальной очистки конфигурации.

## Границы проверки

Реальные сценарии вызывают те же методы, что и кнопки программы; нативные щелчки мышью в этих автоматических сценариях не воспроизводятся. Ручную проверку пользователь выполнил отдельно.

Проверки операций с правилами не подтверждают прохождение конкретного сетевого трафика. Все реальные временные правила были отключены. Полная матрица разных выпусков Windows, масштабов DPI и нескольких мониторов не проверялась.
